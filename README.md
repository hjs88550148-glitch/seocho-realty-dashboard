# 서초구 부동산 브리핑 대시보드 (홍길동부동산)

## 처음 설정
`config.example.json` 을 `config.json` 으로 복사하고 공공데이터포털 인증키를 입력하세요. (`config.json` 은 저장소에 올라가지 않습니다)

## 실행
1. `start.bat` 더블클릭 → 브라우저에서 http://localhost:8650 이 열립니다. (Python 3 필요, 추가 설치 없음)
2. 종료: 검은 창에서 `Ctrl+C`

## 설정 (`config.json`)
- `data_go_kr_key` : 공공데이터포털 인증키 (아파트 매매·전월세 실거래가, 청약홈 분양정보)
- `rone_key` : 한국부동산원 R-ONE 인증키. 입력하면 "주간 아파트가격지수(서초구)" 차트가 자동 표시됩니다.
  비어 있으면 실거래가로 계산한 자체 지수를 보여줍니다. (키 발급: https://www.reb.or.kr/r-one → OpenAPI)

## 기능
- 동별 선택(서초구 전체/반포·잠원·서초·방배·양재·우면·내곡…), 주간/월간/직접지정 기간
- 매매·전세·월세 TOP 10 (최고가순/거래량순) + 지도 위치·최근 실거래가 표시
- 추천매물: 샘플 4건, `+ 매물 등록`으로 추가/삭제 (이 PC 브라우저에 저장)
- 입지분석: 교통(지하철·버스·KTX/SRT/GTX), 학군(초·중·고), 상권(마트·백화점·카페·관공서·병원·공원), 개발계획을 한 화면에 펼쳐서 표시
- 시장동향: 거래량·평당가 추이, 가격지수, 동별 비교, 면적대별 비중, 서울 청약·분양 일정

## 데이터 파일
- `cache/` : API 응답 캐시 (지워도 자동 재수집)
- `data/geocache.json` : 단지 좌표. 새 단지는 처음 표시될 때 자동 검색. 미리 채우려면 `python server.py --warm`
- `data/pois.json`, `data/osm_apts.json` : OpenStreetMap 역·학교·상권·단지 위치
- `static/knowledge.js` : 상호/전화, 노선 정보, 동별 개발계획, 샘플 매물 (직접 수정 가능)
